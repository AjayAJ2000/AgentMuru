# AgentMuru 0.3 Clean MVP Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a qualified Python-first AgentMuru 0.3 MVP with official provider adapters, a task-complete documentation site, coherent GitHub organization, and current PyPI metadata.

**Architecture:** Extend the provider-neutral message contract with durable assistant tool calls, then map the official OpenAI, Anthropic, and Google async SDKs into normalized events without allowing vendor objects into the core. Keep the browser Workspace as the primary operator projection, move the Go runtime under Labs, and publish every public surface from one verified version and capability ledger.

**Tech Stack:** Python 3.10-3.13, FastAPI, SQLite, OpenAI Python 3.1, Anthropic Python 0.122, Google Gen AI Python 2.18, React 18, TypeScript, Vite, Vitest, Playwright, MkDocs Material, Go 1.25, GitHub Actions, PyPI trusted publishing.

## Global Constraints

- The supported MVP is the Python runtime, FastAPI server, browser Workspace, SQLite persistence, governed tools, and optional official provider adapters.
- `FakeModel` remains the default and works without credentials or a network call.
- Provider dependencies are optional and may be imported only from outward integration modules.
- The base package supports Python 3.10 through 3.13.
- OpenAI uses `openai>=3.1.0,<4`; Anthropic uses `anthropic>=0.122.0,<1`; Google uses `google-genai>=2.18.1,<3`.
- The Go terminal runtime is Labs content and is not a primary PyPI installation path.
- Raw credentials, vendor objects, raw exceptions, and unredacted sensitive arguments never enter persistent or public values.
- Built-in SQLite supports one active Runtime process per database and modest write concurrency.
- Active public surfaces contain no BrickFlowUI names or component-framework guidance.
- Version `0.3.0` is published only after all local and hosted qualification gates pass.
